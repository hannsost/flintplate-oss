# FlintPlate Personalbasis

FlintPlate verwendet Code der Palmscout-Recruiting- und Personalplattform für
Identitäten, Teams und Einsatzplanung. FlintPlate bleibt ein eigenständig nutzbares
Gastroprodukt. Die geerbten `HIREOS_*`-Variablen sowie Paket-/Containernamen sind
technische Altbezeichnungen, keine Produktnamen.

Für FlintPlate nur [den dedizierten lokalen Betrieb](LOKALER_BETRIEB.md) verwenden.
